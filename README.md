# 虚拟人体 · 数字孪生平台（界面展示版）

人体健康演化的多尺度计算框架：把器官、细胞、离子通道与药物响应写成可求解的数学问题，在个体化参数下预演给药结果。

本仓库只分发**界面展示版**：原平台首页、科研图表、思维导图、研发看板、细胞实验界面与三维可视化全部保留，可点击、可跳转；计算内核不在此分发，涉及求解的入口会明确提示未开放，不会伪造进度或药效结果。

## 下载

安装包在 **Releases** 页面（`虚拟人体展示版_90MB.zip`，约 71 MB）：

1. 下载 zip 并解压
2. 需要 Python 3.10+，无需安装第三方库
3. 双击 `启动展示版.bat`，或在该目录执行 `python -B server.py`
4. 浏览器打开 `http://127.0.0.1:8792/`（端口占用时自动换端口）

## 可以看什么

- 原平台首页与四套显示风格，保留原导航与器官目录
- 心脏科研图表、细胞组成、国际对标、验证看板、科研图表参考库
- 项目构成、全部器官、心脏、工作心肌细胞、数据来源、机制完备度等思维导图
- PBPK、衰老机制、逆龄与药物设计演示、生命历程界面
- 基因/全元素总览、项目知识图谱、研发可视化
- 心脏程序化 3D、真实解剖 3D、全身解剖查看器、3D 细胞与生命历程 3D
- 原药物模拟设置、运行台、批量测试、报告与对照页的界面

页面左下角「全部页面」可打开完整目录。

## 边界说明

- 首页数值、科研图表与部分细胞状态使用 2026-11-11 采集的模型预设或既有结果快照，不随人群选择自动生成新预测，不是患者数据、临床验证或新计算结果。
- 「基础模型实算」保留可独立运行的细胞群体 → 电活动/简化力学 → 器官代理链，可修改缺血、炎症、年龄、时长等输入。
- CiPA 求解、PK/PBPK、真实候选药与完整多器官后端**未包含**。
- 本项目仅用于科研演示与方法交流，不构成医学、药学或临床结论。
